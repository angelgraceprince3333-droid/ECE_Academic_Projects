# Load Shedding Time Manager for Rural Areas

## Project Overview

The **Load Shedding Time Manager** is a web-based application designed to help people in rural areas access information about scheduled power outages.

The system provides a centralized platform where users can check load-shedding schedules based on their region and date. It also includes an administrative interface that allows schedules to be added, updated, and managed easily.

The main aim of this project is to make power outage information more accessible and help people plan their daily activities accordingly.

## Objectives

- To provide easy access to scheduled power outage information.
- To display daily and weekly load-shedding schedules.
- To organize schedules according to different regions.
- To provide an admin interface for managing outage information.
- To create a foundation for future alert and notification features.

## Technologies Used

- **Python** – Backend programming
- **Flask** – Web application framework
- **HTML** – Web page structure
- **CSS** – User interface styling
- **JavaScript** – Frontend interaction
- **JSON** – Schedule data storage

## Key Features

- User-friendly web interface.
- Region-wise load-shedding schedules.
- Date-based schedule viewing.
- Display of outage start time, end time, and reason.
- Administrative panel to add and update schedules.
- Centralized access to power outage information.

## Working Principle

1. The Flask application runs as a web server.
2. Users access the application through a web browser.
3. Users select their region and required date.
4. The system displays the corresponding load-shedding schedule.
5. The administrator can add or update outage details through the admin panel.

## Future Scope

- SMS and push notifications before scheduled power cuts.
- Integration with a database for improved data management.
- Offline access to previously loaded schedules.
- Mobile application support.
- Integration with public information systems.

## Conclusion

The Load Shedding Time Manager demonstrates how web technologies can be used to solve a practical problem faced by rural communities. It provides a simple and centralized way to access power outage information and can be further developed with automated notifications and additional features.
